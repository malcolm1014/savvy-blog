---
description: Hermetic Correspondence — test or build an analogy by checking it preserves relational structure, not just surface features ("as above, so below").
argument-hint: <source domain → target domain, or the analogy/transfer to check>
---

Apply the principle of **Correspondence** to:

> $ARGUMENTS

Formal object: analogy as a structure-preserving map. In representation, a sound analogy satisfies `a:b :: c:d ⇒ (b − a) ≈ (d − c)` — the *relation* carries, not the surface. Cross-scale consistency: `‖R(h_s) − h_{s−1}‖` small, where `R` maps one scale to the next. As above, so below means the pattern holds under the mapping.

Do this:
1. Make the mapping explicit: list the corresponding elements, source → target.
2. List the **relations** that matter in the source (what acts on what, what constrains what, the direction and shape of each link).
3. Check each relation survives the mapping. A valid correspondence preserves the relational skeleton; a false one shares only surface appearance.
4. Name where the analogy **breaks** — the relations present in the source that have no faithful counterpart in the target. Every analogy breaks somewhere; locate it precisely so you know how far the transfer is licensed.
5. If building across scales, confirm the conclusion at the new scale is consistent with the one below it.

Return: the mapping, which relations carry, where it breaks, and therefore exactly which inferences the correspondence licenses and which it does not.
