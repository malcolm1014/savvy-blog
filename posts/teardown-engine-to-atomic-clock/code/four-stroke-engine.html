What the repo does

It's a Claude Code skill, not an app. You install it once, then ask in plain words — build me a teardown of a mechanical watch — and it writes a single offline HTML page exactly like this one: a machine in 3D, panels reading its real numbers, and an idle self-tour.

Install is npx skills add elvarofficial/teardown -g -a claude-code, then npm install && npx playwright install chromium. Needs Node 20+. It's built on claude-motion, MIT-licensed, 5 stars, one commit.

This page is my demo of that output — the physics below are honest, derived from the slider-crank geometry, not faked.
